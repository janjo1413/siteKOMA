# Koma, Cosmos Serpent

Site do meu deck de Commander simic de stax com a Koma, Cosmos Serpent: cada carta com o motivo de estar no deck, as sinergias, o resumo do plano de jogo, as linhas de vitória, mãos para keepar e as cartas que ficaram de fora. Em inglês e português.

- Deck no papel: https://archidekt.com/decks/15735130/koma_leaker_of_mana
- Ambiente de testes: https://archidekt.com/decks/25677824/area_de_teste_koma
- Perfil no Archidekt: https://archidekt.com/u/janjo1413

## Rodar localmente

```
python -m http.server 8000
```

Depois abra http://localhost:8000.

Imagens das cartas via Scryfall. Magic: The Gathering é marca da Wizards of the Coast.
